Injection Guard Architecture & System Manual

Deterministic multi-stage deep-packet evaluation gateway for foundational LLM inference pipelines. Defends zero-trust boundaries against direct prompt injection, jailbreaks, indirect RAG pollution, and recursive instruction poisoning.

Architecture execution flow

Serial Synchronous / Deterministic 5-Hop Transit
01 STAGE 1

1. Client & RAG Ingestion

Ingests user prompt, conversation history, and retrieved RAG context documents simultaneously into immutable buffers.

[UTF-8 Sanitizer] input
02 STAGE 2

2. Syntactic & Regex Normalization

Strips zero-width unicode, homoglyphs, decoding base64/rot13 layers and flattening escape hierarchies.

[Canonical Engine] code
03 STAGE 3

3. Dual-Layer Scoring

Heuristic pattern matches + transformer embedding similarity against adversarial vector clusters in 1536-dim space.

[Score Model v2.4] analytics
04 STAGE 4

4. Threshold Decision Gate

Compares composite score against strict policy threshold (0.548). Instant refusal synthesis on violation without token leak.

[Gate Enforcer] gavel
05 STAGE 5

5. LLM Dispatch or Intercept

Allowed queries forward to downstream foundation models; blocked requests halted at gateway with audited signature hashes.

[Zero-Leak Boundary] shield

Known limits & operational boundaries

5 AUDITED CONSTRAINTS
warning
1. Novel zero-day semantic obfuscation SURFACE: MULTI-TURN

Multi-turn linguistic re-framing across >10 turns requires conversation memory buffer accumulation.

shield Mitigation: Enable Cross-Turn Context Horizon with 16k rolling token memory buffer.
translate
2. Foreign language low-resource prompts SURFACE: LINGUISTIC COVERAGE

Syntactic rule coverage is highest in English, Spanish, Mandarin, German, and French; low-resource languages rely on vector cross-lingual projection.

shield Mitigation: Activate multilingual mBERT pivot embeddings with strict cross-lingual threshold (0.490).
lock
3. Encrypted or steganographic document embeddings SURFACE: RAG CHUNKS

RAG files containing encrypted payloads or hidden zero-width steganographic markers must be decrypted before ingestion scan.

shield Mitigation: Chain with pre-scan Decryptor Hook and verify SHA256 corpus provenance.
timer
4. Latency overhead BOUND: 11-18ms

Standard evaluation adds 11-18ms of gateway processing time per request under nominal cluster loads.

shield Mitigation: Deploy ONNX Quantized Runtime on co-located TensorRT instances for sub-8ms P99.
terminal
5. High entropy text false positives DELTA: 0.50-0.54 RANGE

Code snippets containing complex regex, base64 data URIs, or raw shell scripts may trigger near-threshold warnings (0.50-0.54).

shield Mitigation: Tag developer prompts with AST parser bypass headers (`x-ig-syntax-bypass: shell-safe`).
